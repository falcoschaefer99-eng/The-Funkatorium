## 4) Service menu (draft)

## Service A — Agentic System Audit
**Who it’s for:** creators/small businesses with messy AI workflows  
**Outcome:** clear architecture + execution plan

**Includes:**
- Workflow teardown (tools, prompts, bottlenecks)
- Gap map (what to automate, what not to automate)
- Prioritized roadmap (quick wins + deeper builds)
- 7-day action plan

**Timeline:** 3–5 days  
**Draft pricing:** €350–€900

---

## Service B — Custom Agent Build Sprint
**Who it’s for:** people who want a working system, not advice slides  
**Outcome:** shipped assistant/automation stack tailored to their process

**Includes:**
- System design
- Prompt + memory architecture
- Tool wiring/integrations
- Testing + handoff docs

**Timeline:** 1–3 weeks  
**Draft pricing:** €1,500–€6,000 (scope-based)

---

## Service C — Maintenance + Evolution Retainer
**Who it’s for:** users of your open-source stack who need reliability and upgrades  
**Outcome:** system stays stable, updated, and useful

**Includes:**
- Monthly updates
- Bug fixes + dependency checks
- Small feature adjustments
- Async support window

**Timeline:** monthly  
**Draft pricing:** €250–€1,500 / month

---

## Service D — Creator Stack Setup (fast offer)
**Who it’s for:** solo creators who need a practical starter system fast  
**Outcome:** usable daily stack in one week

**Includes:**
- Tool stack setup
- 2–3 custom workflows
- Content/research assistant baseline
- 60-min handoff call

**Timeline:** 5–7 days  
**Draft pricing:** €600–€1,800

## 5) Pricing visibility strategy

- **On X/social posts:** no detailed pricing; lead with outcomes and examples
- **On website service pages:** transparent ranges + what changes price
- **CTA copy:** “See full scope + pricing on site”

Reason: cleaner social messaging, serious buyers self-qualify on site.
